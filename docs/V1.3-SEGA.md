# V1.3 Sega and channel layout

`Registry.cpp` recognizes VGM after bounded CRC-checked VGZ inflation. `VgmBackend.cpp` checks header offsets, command/data lengths, PCM reads/seeks, timed end/loop boundaries and allowed chips/commands before constructing libgme cores. Data-bank, register, legacy DAC and wait commands are supported; streaming DAC and other-chip commands fail explicitly. Native looping is cleared and the actual first-pass wait count becomes metadata duration, so the player owns Repeat and folder advance. Repeat restarts the entire file rather than jumping to the embedded loop point. 64MiB encoded/decoded input and one-hour first-pass limits apply.

`third_party/gme-sega-patch` splits Genesis YM2612 FM 1–6, DAC and four SN76489 voices (11 total). SMS uses four SN76489 voices, or 18 voices with YM2413: FM 1–9, hi-hat, cymbal, tom, snare, bass drum and four PSG voices. Rhythm mode reuses FM 7–9 internally; inactive outputs remain silent. YM2413 is implemented using bundled MIT emu2413, replacing upstream's silent stub. Muting clears stale emu2413 per-channel output samples. GENS YM2612 is selected for performance with synchronized full + isolated cores. No invented waveforms or FFT separation are used. FM emulation is not guaranteed cycle-accurate to hardware.

`ChannelLayout.hpp` is shared by painting, channel-label clicks, volume +/- and slider dragging. Counts above eight use a center-divided two-column layout with enough rows for every declared voice. Compact labels/controls fit 31 N64 items; F9 hides individual volume controls and retains label mute. `Window::visibleChannels` now filters only unused NES DMC, not silent N64 slots. Channel identity/order remains stable as sound starts or stops.

The user Sonic folders contain 35 VGM files (19 Genesis, 16 SMS), checked for the first six seconds, seek/replay and all-channel mute. Authored fixtures cover PSG, YM2413 melody/rhythm, YM2612 FM/DAC/PSG, VGZ CRC, malformed/truncated commands and mixed VGM/VGZ natural folder order. No commercial music is included in either release archive. See VALIDATION.md for final results and limits.
